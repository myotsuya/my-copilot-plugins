# POWER EGG WebDB作成

自然言語の依頼から、POWER EGG WebDBのDB定義ZIP候補を作成するプラグインです。

## 使い方

プラグインを選択し、「備品管理用のWebDBを作って。備品名、状態、数量、担当者、備考が必要」のように依頼します。項目・型・一覧・画面の指定があれば併せて伝えてください。見た目は依頼者の指定を優先し、指定がなければ用途に合う構成を選びます。

ZIPはルート直下にdatabasedef.xmlとcertificate.txtの2ファイルを格納します。ファイル作成とPython 3.9以降の実行環境が必要です。新たな外部サーバー接続やPOWER EGGへの自動取込は含みません。

## 同梱内容

- 提供された仕様mdと追加サンプルTXTの原本
- 9件の用途別XMLと索引、仕様本文・XML実例
- 原本26件の復元用データと提供されたPython補助コード
- 基本生成・ZIP梱包・限定的なローカル検査を行う追加スクリプト
- Pythonがない場合に利用するPowerShell梱包スクリプト

## 確認範囲

直接生成したZIPは公式非対応・実機未検証の候補です。ローカルの整合性確認を通過しても取込成功は保証しません。明細・通知・計算等の高度な機能は観測XMLに基づく個別実装が必要です。権限、組織、参照先、通知先等は取込先で確認・設定してください。

公式に沿う定義ZIPが必要な場合は、POWER EGG上でDBを作成し、外部出力してください。
